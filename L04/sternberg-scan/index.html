Sternberg Memory Scanning

Each trial shows a small memory set of digits (1–6 of them), briefly. Then a single probe digit appears — decide as fast as you can whether it was in the set or not in the set.

Keys: J = present (in the set), F = absent (not in the set) — or tap the buttons. Answer fast: we are timing you.

30 trials · about 3–4 minutes. Sets are the same size within a trial, and vary from 1 to 6 items.

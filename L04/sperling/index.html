Sperling (1960) — Iconic Memory

You will see a 3 × 4 grid of letters flash up very briefly, then disappear. There are three kinds of trial:

  • Whole report — type as many letters as you can from the whole grid.
  • Partial report — a tone tells you which row to report: high = top, medium = middle, low = bottom.
  • Delayed partial report — the tone comes a second later, after the grid has faded.
9 trials · about 3 minutes. Type only letters you actually saw. Use the on-screen keyboard on a phone. Note: browsers can't reliably flash for the original 50 ms — here the grid shows for 150 ms.
